# HEXA DEFENSE — ゲームデザイン・経済バランス表

## セッション設計
- 全50ウェーブでVICTORY
- チェックポイント: W10刻み(W10/20/30/40)。到達済みなら次ランそこから開始可能
- 中断セーブ: 1スロット上書き式。ラン中状態を完全保存

## 成長システム

### A. XPレベルアップ（ラン内・無料・ランダム3択）
| カード種別 | 効果 |
|---|---|
| 連射速度 | fireInterval × 0.80 |
| ダメージ | dmg × 1.40 |
| 射程 | range × 1.15 |
| 弾速 | bulletSpeed × 1.15 |
| HP回復 | hp + 30 (即時) |
| 最大HP+ | maxHp + 30, hp + 30 |

必要XP: `20, 35, 55, 80, ...` (前×1.3+端数切り捨て、最大500で頭打ち)

### B. コインショップ（ラン内・任意タイミング）
- HUD「SHOP」ボタンで開く（ポーズ）
- 品目: 上記Aと同じ数値強化 + HP回復(即時)
- 基本価格10コイン、購入ごと×1.5倍（端数切り上げ）

| 初期HP+ | +20/段 | 40メタコイン |
| 初期射程+ | +5%/段 | 40メタコイン |

## ボス行動パターン
### チャージャー (W10 / W30)
1. ランダム移動(3〜5秒)
2. 予告線表示(0.8秒)
3. 高速突進(突進速度=通常の5倍)
4. W30版: 着弾時に衝撃波ノックバック追加

### サモナー (W20 / W40)
1. 外周をゆっくり周回
2. 一定間隔で雑魚召喚(通常の1.5倍速)
3. 遠距離弾を定期発射
4. W40版: 召喚数・弾数が増加

## 必殺ゲージ
- 与ダメージ × 0.5 分蓄積。満タン = 1000
- 発動効果: 全敵に dmg×8 + ノックバック(中心から200px押し出し)
- 演出: 全画面フラッシュ(白0.6秒) + リング状衝撃波 + 画面シェイク(0.4秒)

## HP回復系統
1. ウェーブクリア時 +20 HP（maxHP上限）
2. ショップで購入（即時 +30）
3. 敵撃破5%でアイテムドロップ → タワーに漂い接触で +25 HP
4. 3択カード「最大HP+」で maxHp/HP 同時+30

## 難度曲線（初期バランス目標）
- 初見(恒久強化ゼロ)でW3〜4敗北
- 恒久強化3〜4回でW10前後到達
- チェックポイント+強化でW20台到達

## リトライ導線
死 → メタコイン獲得演出 → 「恒久強化へ」or「即リトライ」
目標: 死から再戦開始まで15秒以内・5タップ以内

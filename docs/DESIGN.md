## ボス行動パターン
### チャージャー (W10 / W30)
1. ランダム移動(3〜5秒)
2. 予告線表示(0.8秒)
3. 高速突進(突進速度=通常の5倍)
4. W30版: 着弾時に衝撃波ノックバック追加

### サモナー (W20 / W40)
1. 外周をゆっくり周回
2. 一定間隔で雑魚召喚(通常の1.5倍速)
3. 遠距離弾を定期発射
4. W40版: 召喚数・弾数が増加

## 必殺ゲージ
- 与ダメージ × 1.0 分蓄積。満タン = 1000
- 満タン必要与ダメ: **1000ダメージ**(W5ボス込みで概ね1ウェーブ1回体感)
- 発動効果: 全敵に dmg×8 + ノックバック(中心から200px押し出し)
- 演出: 全画面フラッシュ(白0.6秒) + リング状衝撃波 + 画面シェイク(0.4秒)

## HP回復系統
1. ウェーブクリア時 +20 HP（maxHP上限）
2. ショップで購入（即時 +30）
3. 敵撃破5%でアイテムドロップ → タワーに漂い接触で +25 HP
4. 3択カード「最大HP+」で maxHp/HP 同時+30

## 難度曲線（初期バランス目標）

### 設計意図
**「武器の気持ちよさを体験してから死ぬ → 再挑戦動機」**
W5ボスを倒して武器を初めて手に入れ、その爽快感を味わった直後にW6〜7で限界が来る。
「あの武器でもっと先へ行きたい」という動機で次のランに向かわせる。

### 2段階カーブ
| フェーズ | ウェーブ | 特徴 |
|---|---|---|
| イントロ期 | W1〜5 | 緩やか。初見でも確実にW5ボス撃破→武器獲得できる |
| 加速期 | W6〜 | 急加速。武器1個でも1〜2ウェーブで限界 |

- **目標**: 初見(恒久強化ゼロ)でW5ボス撃破・武器獲得後にW6〜7敗北
- フェーズ境界と各フェーズの係数は独立したCONFIGキー(`WAVE_PHASE_BREAK` / `WAVE_HP_SCALE_EARLY` / `WAVE_HP_SCALE_LATE`)で管理
- 恒久強化3〜4回でW10前後到達
- チェックポイント+強化でW20台到達

## 倍速ボタン
- HUD右側(LVパネルの下)に「x1→x3→x10」サイクルトグルボタン(デフォルトx3)
- サブステップ方式: 固定 `subDt=1/60s` で `update()` を倍率回数呼ぶ(弾すり抜け防止)
- パフォーマンス対策:
  - x5以上はパーティクル/弾トレイルを30%に間引き
  - 1フレーム内処理が8msを超えたら残りを次フレームへ持ち越し(溜まりすぎはcap抑制)
- 等倍のまま: draw・演出タイマー(フラッシュ/シェイク)・hexRot
- 必殺/XP/コイン獲得レートは倍速の影響なし(進行が速くなるだけ)
- ポーズ中(レベルアップ等)はSTATEチェックで即停止、倍率設定は維持
- 設定は `localStorage('hd_settings')` の `speedIdx` に保存

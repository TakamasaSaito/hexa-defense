# 021: レアドロップを一時効果に変更

日付: 2026-08-01
状態: 採用

## 決定

レアドロップ(金色六角形)の効果を恒久的なサブウェポン・バリア増加から、
12秒間持続する一時効果(REINFORCE/OVERLOAD/TIME WARP)に全面変更する。
サブウェポンの増加経路はレベルアップ3択とボス報酬のみに一本化する。

## 理由

レアドロップでサブウェポンが恒久的に増える仕組みにより、プレイヤーが
「いつ何が増えたのか分からない」状態になっていた。
成長は選択の結果であるべき、という原則に反する。

比較した案:
- 恒久増加維持: 問題を解消しない
- レアドロップ廃止: 廃止では代替報酬がなく単調になる
- 一時効果化(採用): 「今取った、今だけ強い」が明確。LUCK投資の意義も維持

## 影響

- RARE_EFFECT_POOL → ['REINFORCE', 'OVERLOAD', 'TIMEWARP'] に変更
- 援軍砲台(4基/12秒)・過負荷(DPS x7.5/12秒)・時間減速(敵速x0.22/12秒)を追加
- レベルアップ3択のサブウェポン重みを CARD_SUB_WEIGHT: 3→4 に引き上げ(ペース維持)
- タイトル画面: SP/HELP/DATAボタンを横並び小アイコン行に整理

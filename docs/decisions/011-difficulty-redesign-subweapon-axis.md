# 011: 難度カーブ再設計とサブウェポン軸化

日付: 2026-07-31
状態: 採用

## 決定

1. **Fix: 属性選択・チェックポイント選択でタイトル画面が透けて見えるバグ修正**
   - `openCheckpointScreen()` でタイトル画面を先に非表示化し、BACK時に復元する
   - 画面の`background:rgba(3,7,15,0.65)`は半透過のため、スタック上の下層スクリーンが透過して見えていた

2. **難度カーブ帯別再設計**: `WAVE_HP/SPEED/SPAWN_SCALES` を5帯で再設定
   - W1-10「立ち上げ」: 現状維持(主武器強化に集中できる易しい帯)
   - W11-30「拡張」: HP/速度は緩やか、スポーン数少し増加(サブウェポン習得期)
   - W31-40「最難関」: HP×1.5増・速度×1.3増・スポーン数×1.1増 → 本作最高難度
   - W41-50「爽快」: HP/速度はW31-40より低下、スポーン数は最大(大群一掃の爽快感)

3. **成長軸→サブウェポン化**
   - W11以降のXPレベルアップカードプールにサブウェポン強化カードを追加(重み2倍)
   - サブウェポン上限引き上げ: orbital 3→6, satellite 3→5, field 3→5, subTurret 2→4
   - 武器報酬プールの上限も同様に引き上げ
   - レアドロップの上限チェックも更新

4. **ボス大幅強化(W31-40重点)**
   - DIVIDER(W30): 2800→4200 (W21-30末尾、最難関前哨)
   - BARRAGE II(W35): 3400→5500 + 初期弾幕間隔を短縮
   - SUMMONER II(W40): 5500→8000 (最難関帯のラスト)
   - CHARGER III(W45): 7000→9500 (爽快帯でも手応え)
   - FINAL BOSS(W50): 9000→12000 (クライマックス)

## 理由

- W50クリア達成後の課題は「帯ごとの体験設計」。現在はW31-50が均一に難しいが、メリハリがない
- W31-40を「最難関」にすることでプレイヤーが達成感を感じてW41-50「爽快」を体験できる
- サブウェポンのXPカード登場により「W10以降はサブウェポンに投資する」という判断軸が明確になる
- チェックポイント画面はタイトル画面と同じ`z`スタックで重なっていたため半透過バグが発生していた

## 影響

- 既存セーブデータの互換性: `weapons.orbital/satellite/field/subTurret` の値はそのまま使用可。上限が増えるだけ
- `WEAPON_CARD_DEFS` の`names`/`descs`配列を6段階まで拡張(orbital)・5段階(satellite/field)・4段階(subTurret)
- `subTurretAngles`/`subTurretFireTimers` を4要素配列に拡張
- `CFG.SUB_TURRET_OFFSETS` を4エントリに拡張

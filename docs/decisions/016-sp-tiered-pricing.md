# 016: SP価格を固定から逓増に変更

日付: 2026-07-31
状態: 採用

## 決定

基礎ステータス(ATK/DEF/SPD)のSP単価を固定1から
`cost(n) = round(2.59 * 10^(n/10))` の逓増式に変更する。
サブウェポン系統は `cost(n) = round(1.5 * 2^n)` の緩めカーブ。
目標累計コスト: Lv5≈22SP / Lv10≈90SP / Lv20≈991SP / Lv30≈9,993SP。

SP獲得式も `floor(wave*0.06)+boss*1` から `floor(wave*0.5)+boss*3` に変更。
1ラン(W20-30到達)で22〜33SP獲得が標準。

## 理由

固定1SP価格では貯まったSPを一度に注ぎ込めてしまい、
ATTACK Lv.76(DMG×31.06)のような破綻状態が実際に発生した。
旧獲得式(SP_WAVE_RATE:0.06)では1ランのSP獲得が少なすぎ、
蓄積後に一気投資する行動を誘発していた。

逓増により各レベルに異なるコストが生まれ、
「稼いでも稼いでも少しずつしか伸びない」
メタ進行本来の体験を確保できる。

## 影響

- v2セーブデータはv3マイグレーションでリセット・払い戻し(上限500SP)
- UIに「次の価格: N SP」を表示、残高不足時は+ボタンをグレーアウト
- 長押し連続加算は維持(コスト上昇により自然に止まる)

# 008: 難度大幅引き上げとバリア導入

日付: 2026-07-30
状態: 採用

## 決定

1. 難度を大幅に引き上げ、「恒久強化フルコンプ前提でW50クリア可能」な構造に再設計する。
2. 最大HP強化を廃止し、バリア(回数制ダメージ無効)に置き換える。
3. PULSEをスタン効果から全方位弾に変更する。
4. ボスをW5刻みに増やし、新ボス2種(弾幕型・分裂型)を追加する。

## 理由

- 従来の難度では恒久強化なしでもW10〜20程度まで到達でき、メタ進行(恒久強化)の意味が薄かった。
  ローグライト的な「積んで初めて勝てる」構造への転換が必要。
- 最大HP増加はプレイヤーに知覚されず成長実感がなかった。
  バリアは枚数が視覚表示され、消費が体感できる希少資源として機能する。
- スタンが強すぎ、かつ他の必殺(RAILGUN/OVERDRIVE)との役割差が不明瞭だった。
  全方位弾は「囲まれたときに面で捌く」明確な役割を持つ。

## 影響

- 初見クリアは事実上不可能になる(設計意図)
- バリアは恒久強化唯一の防御系資源となる(ショップ/カードで増加)
- スタン依存のプレイスタイルは消滅。フェーズ2・3持ちボスへの対応が必要になる
- docs/DESIGN.mdのシミュレーション表・将来拡張節を更新すること

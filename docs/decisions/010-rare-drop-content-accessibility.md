# 010: レアドロップ導入とコンテンツ到達性の改善

日付: 2026-07-30
状態: 採用

## 決定

1. **レアドロップ新設**: 敵撃破時に金色六角形のレアアイテムをドロップ(W1から)。ボス撃破は必ず1個。取得時に即座に効果を適用する。
2. **レベルアップカードに属性強化追加**: 「選択属性Lv+」「属性効果範囲+」をカードプールに追加。
3. **新必殺 BEAM**: ドラッグで向きを操作する操作型ビーム特殊兵器を4種目として追加。W15で解放。
4. **難度カーブ緩和(W1〜20帯)**: WAVE_HP_SCALES/SPEED_SCALESのW1-10・W11-20帯を約15〜25%引き下げ。W21以降の急峻さは維持。
5. **恒久強化の天井撤廃**: 主要5系統(dmg/rate/hp/range/coinGain)の上限を事実上無限に変更。Lv11以降は価格逓増・効果逓減でバランス維持。
   > **廃止:** この恒久強化ツリーは #015(SP制移行)で全廃。現在のメタ進行はSP制。

## 理由

- W10以降の武器報酬・設置型フィールドなど実装済み要素の大半がプレイヤーに届いていない
- 「W10前後で詰まる → 報酬が見えない → 離脱」のサイクルを断つため、到達性を優先改善
- レアドロップは「ボス報酬より手前で新要素が手に入る」体験を作り序盤から画面が派手になる設計
- BEAMは「プレイヤーが直接操作して敵を焼き払う」本作最大の爽快演出として追加
- 恒久強化の天井は#14で8系統に拡張後も再び到達しやすくなっており、長期継続プレイのモチベーションを維持するために撤廃

## 影響

- 難易度全体がW15帯まで緩和される(後半W21〜の難しさは保持)
- 恒久強化のセーブデータはmigrateSaveで後方互換を維持
- BEAMのドラッグ操作と設置型フィールドのタップは排他処理で競合を防ぐ
- INDEX.html単体・ライブラリなしの制約は変わらない

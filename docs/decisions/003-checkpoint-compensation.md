# 003: チェックポイント開始時の補償

日付: 2026-07-25
状態: 採用

## 決定
チェックポイント(W10/20/30/40)から開始する場合、
初期コイン(未定・CONFIG値)と武器1個を補償として支給する。
W1からの素開始と同じ状態では開始しない。

## 理由
W10以降はW5武器報酬・W6〜9のXPレベルアップ・コイン蓄積を経た強化状態が前提の難易度設計になっている。
チェックポイントから素開始すると「強化ゼロでW10以降に放り込まれる」状態となり、
恒久強化の有無にかかわらず即死に近い体験になる。
これでは「W10到達済みなら便利に使える」という設計意図が壊れる。

## 影響
- チェックポイント選択画面に補償内容を明示する(「武器1個 + コインXX枚 で開始」)
- 補償コイン量はCONFIGキー CHECKPOINT_START_COINS で管理
- 補償武器の選択UIは「2択表示(チェックポイント開始時のみ)」で実装(M3スコープ)

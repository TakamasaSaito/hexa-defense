# 005: 難度カーブ再設計(旧001廃止)

日付: 2026-07-30
状態: 採用(→001を廃止・本記録で置換)

## 決定
旧B案(初見W5突破→W6-7敗北)を廃止し、W5ミニボス自体を初見の壁とする。
初見はW5ミニボスで敗北する設計に戻す。
初見の「気持ちよさ体験」役はPULSE必殺(初期所持)が担う。

## 理由
B案廃止理由: ボス強化(HP 300→600)と両立しない。
強化したW5ボスをW1-4の緩い蓄積だけで突破できなくなる→B案の前提が崩れる。
PULSE(初期所持・コスト33%)により、W1-4で必殺の気持ちよさを体験できる。
「PULSEを使い切ったあとにW5で敗北→RAILGUN/OVERDRIVE目標→再挑戦動機」の流れを設計する。

## 影響
- 001の「W5小型ボスHP300・W5初回武器報酬」を変更(HP600、武器報酬はW5継続)
- W6-7の急加速は撤廃。全ウェーブで継続的な難易度上昇カーブを維持
- WAVE_PHASE_BREAK CONFIG値は削除せず保持(後方互換)

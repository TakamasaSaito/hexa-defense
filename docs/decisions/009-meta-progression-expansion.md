# 009 — 恒久強化を10段階に拡張し、属性をW5報酬のビルド軸に変更

日付: 2026-07-30  
Issue: #14  
状態: **廃止(→015で置換)**

> 旧恒久強化ツリー(メタコイン×5系統×10段階+新3系統)は #015(ラン内ショップ廃止・SP制移行)で全廃。
> 現在のメタ進行はスキルポイント(SP)制で一本化。属性W5報酬の仕組みは継続。

## 決定

1. 既存5系統の恒久強化を5段階 → 10段階に拡張
2. W5ボス報酬を「炎/氷/雷の3択」に変更し、ランのビルド軸を前倒しで決める
3. 新3系統(初期バリア/必殺ゲージ効率/初期属性Lv)を追加

## 理由

恒久強化5系統が早期にMAXに達し、メタコインが3000以上の死に資源と化していた。
また属性がW10〜の後半取得だったため、周回ごとのビルド差が生まれにくかった。

## 具体設計

### 恒久強化 価格設計
- Lv1〜5: 既存通り(base=25, scale=1.8)
- Lv6〜10: 新ティア(base=80, scale=1.4) — ゆるやかな増加でコイン過多を吸収
- フルコンプ想定コスト: 約9400メタコイン = 35〜40ラン相当

### 恒久強化 効果設計(後半ティアで増強)
| 系統 | Lv1〜5/段 | Lv6〜10/段 |
|------|-----------|------------|
| ダメージ | +20% | +30% |
| 連射速度 | 間隔-15% | 間隔-20% |
| HP | +25 | +50 |
| 射程 | +10% | +15% |
| コイン獲得 | +18% | +25% |

### 新系統
| 系統 | 効果 | 段数 | 価格(base, scale) |
|------|------|------|-------------------|
| 初期バリア | 開始時バリア+1 | 3 | 200, 1.8 |
| 必殺ゲージ効率 | 蓄積速度+20% | 5 | 25, 1.8 |
| 初期属性Lv | W5選択属性+1Lv(Lv2 or Lv3スタート) | 2 | 25, 1.8 |

### W5属性3択
- W5ボス撃破後: 炎/氷/雷の3択画面
- 選択属性 = ランの軸。ボス報酬プールで3倍重みで出現
- 他属性はLv1から通常プールに残る(重み1倍)
- 炎=単体高火力 / 氷=減速で時間稼ぎ / 雷=多数の敵に強い

## 不採用事項
- W5以前での属性取得: ゲームが始まってすぐビルドを決めさせるのはUX上良くない
- 属性専用ルートの完全分離: 武器の混合自由度を維持するためフラット設計を継続

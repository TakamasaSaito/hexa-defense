# 007: 強化を数値変化から視覚変化に再設計

日付: 2026-07-30
状態: 採用

## 決定
連射強化の効果を「発射間隔短縮」から「弾の条数増加(1〜4条)」に置き換え、
ダメージ強化の効果を「ダメージ数値増加」に加えて「弾の太さ・色変化」で可視化する。
高レベル到達時(連射Lv4 or ダメージLv5)に追跡ミサイルを定期発射する。
総DPS曲線は改修前と同等になるよう弾数分で1発ダメージを等分する。

## 理由
連射・ダメージの数値上昇はプレイヤーに知覚されず成長実感がなかった(既存課題)。
弾数・弾の見た目・追跡ミサイルという視覚的段階に置き換えることで、
強化するたびに目に見えて変化し「強くなった感」が得られる。
DPS等分により既存バランスは維持し、見た目の派手さのみを増やす。

捨てた案: 弾の尾を長くする(実装コスト高・iOS性能リスク)、
エフェクト音変化のみ(視覚変化が乏しい)。

## 影響
- bullets配列の各要素に r / bcolor / bglow フィールドが追加される
- missiles配列・missileTimer変数が新設される
- enemies に stunTimer フィールドが追加(PULSE用)
- PULSE役割変更: ダメージ主体→スタン主体(DMG_MULT 8→2、stun 2秒)
  > **廃止:** PULSEスタン効果は #008 で全方位弾幕(面制圧)に変更。stunTimerフィールドは削除済み。
- XP_BASE 20→50、XP_CAP 500→600(レベルアップ頻度を1ウェーブ1回程度に緩和)
- SPECIAL_DMG_RATIO 0.5→0.25(ゲージ蓄積を半減)

# 015: ラン内ショップ廃止とSP制への移行

日付: 2026-07-31
状態: 採用

## 決定

ラン内ショップ・ラン内コインを廃止し、恒久強化ツリー(8系統)をスキルポイント(SP)制に一本化する。
SPは到達ウェーブ数に比例して獲得(W1あたり×係数+ボス撃破ボーナス)。
基礎3系統(ATTACK/DEFENSE/SPEED)は上限なし・逓減効果。サブウェポン5系統は別枠で初期値に影響。

## 理由

- ラン中にショップを開く時間的余裕がなく、テンポを削いでいた
- レベルアップ3択と購入強化の役割が重複していた
- 恒久強化ツリーが複雑化し、成長の見通しが悪かった
- SP制に一本化することで「1ポイントずつ振る」粒度の細かいメタ進行を実現する

## 影響

- ラン内コイン・SHOPボタン・ショップ画面が削除される
- HP回復手段が減るためレアドロップ回復の出現率と回復量を上方修正して補う
- 既存SaveDataはマイグレーションで旧メタコイン・旧強化Lvを相当SPに換算して引き継ぐ
- SVGアセット差し替えにより絵文字アイコンがすべて統一デザインのSVGに置き換わる
- STATUS画面が刷新され未解放要素もグレー表示で一覧できる

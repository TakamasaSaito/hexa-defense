# 017: SPを基礎能力に限定し、サブウェポンをラン内成長に移行
日付: 2026-07-31
状態: 採用

## 決定
SPで振れる系統を ATK / DEF / SPD / BARRIER / LUCK の5系統のみに限定する。
サブウェポン5種(サブ砲台/オービタル/衛星砲台/設置型/範囲爆発)はSP対象から外し、
すべてのランでLv0開始・レベルアップ選択/レアドロップ/ボス報酬でのみ取得できるようにする。

## 理由
- SPでサブウェポン初期Lvを購入できたため、ラン開始時点で完成形となり、
  ラン内の「だんだん強くなる」体験が失われていた
- メタ進行(SP) = 基礎能力の底上げ、ラン内 = ビルド構築、と役割を分離することで
  毎ランのビルドに差が生まれ、リプレイ性が向上する
- 比較選択肢: SP上限だけ下げる案 → 完成形になるまでの時間が延びるだけで問題の本質は解決しない

## 影響
- BARRIER(開始バリア枚数)・LUCK(レアドロップ率+)をSP系統に追加
- W1からレベルアップでサブウェポンカードが出現(CARD_SUB_WAVE: 11→1, WEIGHT: 2→3)
- RARE_EFFECT_POOLにsub_turret・explosionを追加
- v3セーブデータ: サブウェポン投資SP全額払い戻し(v4マイグレーション)
- W1〜5の敵HP基礎値を小幅削減(主砲のみで序盤を凌げるよう)

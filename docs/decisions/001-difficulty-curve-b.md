# 001: 難度カーブB案採用

日付: 2026-07-25
状態: 採用

## 決定
W1〜5をイントロ期(緩やか)、W6〜を加速期(急加速)とする2段階カーブを採用する。
初見プレイヤーはW5小型ボスを撃破して武器を1個獲得した直後にW6〜7で敗北する。

## 理由
比較した案: W3-4で初見敗北させる案(A案)。
A案では武器を一度も触れずに死ぬため「負けたが武器が面白そう→再挑戦」の動機が生まれない。
B案はW5ボス撃破・武器取得という達成感を先に与えてから限界を来させるため、
「武器の気持ちよさを体験してから死ぬ→再挑戦動機」の設計意図を満たせる。

## 影響
- CONFIG に WAVE_PHASE_BREAK=6 を独立キーとして設置
- W5に小型ボス(チャージャー弱体版, HP300)を配置し初回武器報酬を発生させる
- W1〜5の係数とW6〜の係数を独立したCONFIGキーで管理する

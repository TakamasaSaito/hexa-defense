# 019: チュートリアル方式 — インラインヒント + HELPボタン

日付: 2026-08-01
状態: 採用

## 決定

ゲームを止めない軽量オーバーレイ(インラインヒント)と、タイトル画面のHELPボタンを組み合わせる。  
チュートリアル専用ステージやポーズ強制UIは設けない。

## 理由

- 既存の「新敵告知」オーバーレイ(newEnemyAlert)と同じ仕組み(timer減算・canvas描画)を流用できるため実装コストが低い
- ゲームを止めない方針(Issue #27要件) をそのまま実現できる
- HELPボタンからいつでも全要素を確認できるため、初回フラグ付きヒントが消えた後もフォローできる
- 表示済みフラグ(saveData.seenHints)はセーブデータに保存し2回目以降は出さない

## 比較した選択肢と捨てた理由

- **A. 専用チュートリアルステージ**: 既存のウェーブ構成を壊す。実装コスト大
- **B. ポーズ強制ダイアログ**: ゲームフローを断ち切る。iOS Safari の alert 禁止制約に抵触する懸念
- **C. DOM通知バナー(外側)**: Canvas 内の状態と視覚的に分離されて読みづらい

## 影響

- saveData に seenHints フィールドが追加(バージョン互換性あり・マイグレーション不要)
- 7つのトリガー: W1/初回LevelUp/RareDrop/W5属性選択/初回サブウェポン/初回バリア/初回敗北

# 013: ボス大幅強化・フィールド切り札型再設計・必殺コスト調整
日付: 2026-07-31
状態: 採用

## 決定
- 全ボスHPを1.5〜3倍に引き上げ。W30-40帯とFINAL BOSSを「明確な壁」に設定
- フィールド武器をCD制から総使用回数制(初回3回)に変更し、効果範囲を大幅拡大
- OVERDRIVE/BEAMコストを100%→70%に引き下げ(PULSE 33% / RAILGUN 50% / OVERDRIVE 70% / BEAM 70%)
- ポーズメニューからステータス画面を追加
- 衛星砲台に発射フラッシュ追加、射程リング常時表示化

## 理由
- ボスが弱く手応えがない: W31-40 FINAL BOSSは「明確な壁」として機能すべき
- フィールドが狭すぎ(radius 65〜95)て設置する意味が薄く、切り札感ゼロ
- OVERDRIVE/BEAMコスト100%は重すぎて1ラン中ほぼ使われない(機会損失)
- 強化状況が見えず「次に何を伸ばすか」の判断ができない

## 影響
- フィールドのsave/restoreRunに`fieldUsesLeft`追加(後方互換: sr.fieldUsesLeft || 0)
- フィールドはCDシステムを廃止。既存のfieldCooldown変数は0のまま残存(未使用)
- 旧フィールドの「同時複数設置」は廃止し1枚同時設置に変更
- 必殺コストHTML表示(sp-cost span)も更新済み
